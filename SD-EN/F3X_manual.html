F3X.no tool for RadioMaster TX16S

Setup wizard and pilot setup for gliders (EdgeTX). For TX16S MK3 (800×480) and MK2 (480×272). Needs EdgeTX 2.11 or newer (2.12 recommended). Version 27.10.2026.

1. Before you start: ELRS 4 and CH5

Transmitter and receiver must run ExpressLRS 4. In ELRS 3, CH5 is always the arming channel and is on/off only (−100 / +100). Flap R is on CH5, so it cannot be adjusted smoothly with ELRS 3.

  1. Update the internal module in the transmitter and all receivers to ELRS 4. Use ExpressLRS Configurator and the same bind phrase on all of them. ELRS 4 and ELRS 3 do not link with each other.
  2. MDL → Setup → Internal RF → Arm using: Switch, switch ON. CH5 then becomes a normal channel. Needs EdgeTX 2.11 or newer.
  3. The ExpressLRS menu (SYS → Tools → ExpressLRS): Packet Rate 100Hz Full and Switch Mode 8ch.
  4. After the change: power-cycle the receiver and check that C (connected) shows at the top of the ExpressLRS menu.

2. Installation

  1. Connect the radio to the PC/Mac with USB and select USB Storage (SD).
  2. If you have an older version: first delete the folder SCRIPTS/RM and SCRIPTS/TOOLS/F3X.lua / F3X.luac. Keep SCRIPTS/RM/DATA if you want to keep the pilot profile and models. Otherwise the radio may use old compiled .luac files together with the new ones.
  3. Copy the folders SCRIPTS and SOUNDS from the package to the root of the SD card (merge with what is there). The voice callouts replace SOUNDS/en/launch.wav, normal.wav and speed.wav.
  4. Eject the disk and unplug USB.
  5. SYS → Tools → F3X.no.

Start with a new, empty model. The wizard overwrites the mixes on the channels it uses (CH1–9 and CH17–21).

3. How to adjust

S1 = coarse adjustment, S2 = fine adjustment. This applies to center, endpoints, throws and all adjustments in menu 6.

  • Set S1 and S2 to center each time a new surface or a new side comes up. Until then the screen shows “Set S1 and S2 to center to start” in red, and nothing changes. This keeps the value from jumping.
  • S1 covers the whole range over half its travel. S2 fine-tunes a little around the value.
  • If a control is at the end: press Reset pot and center both again. The value is held meanwhile.
  • Save / Confirm saves the value and moves on.
  • PAGE> and PAGE< go to the next and previous surface without saving. The surface gets its previous value back. That way you can adjust one surface without touching the approved ones.
  • Keys 1–6 below the screen jump to channel 1–6 (without saving). In endpoints the same key changes side. The motor is never on the keys.
  • You can also tap a surface on the model picture.
  • In center and endpoints all surfaces are held at center, so you can use the neighbouring surface as a reference.

With 2 wing servos, CH1 and CH6 are used and CH2/CH5 are empty.

Your own channels: Pilot setup → Change one item → Channels. Tap a row for the next channel. Two surfaces cannot share a channel (shown in red). The channels apply to all models on the radio. If you change them, run the wizard (0–5) again for the models. The start page tells you.

Setup wizard

P Pilot setupPick the switch for each function by flipping it. Default: SE Thermal/Speed, SD motor on/off, SG motor power, SH trainer/test switch, RS camber, Throttle = butterfly, T3 aileron differential, S1 volume. Optional: vario on/off and extra channel on/off (CH8, −100 % off / +100 % on). “Channels” sets the channels.
0 Model config2 or 4 wing servos, cross or V-tail, motor and which flight modes are used.

2 CenterSet each surface neutral with S1/S2. Normal surfaces use PPM center (±500 µs). Flaps use subtrim, and above 100 % it continues in PPM center (up to approx. ±195 %), because the flap neutral can be far towards one end.
3 EndpointsOne side at a time. The first time, the servo only goes 20 % out from neutral, so it does not hit a stop. Adjust out to the mechanical stop. Above 100 % needs Extended limits.
4 ThrowsThrow per surface and side for aileron, elevator and rudder. Aileron down is 60 % by default (differential).
E ESC calibrationOnly with a motor. Remove the propeller. Full Throttle (1998 µs), connect the battery, wait for the beeps, then zero Throttle (1003 µs).
5 Write setupWrites mixes, curves, flight modes, logical switches, special functions and timers. The first time by hand. After that the setup is written automatically when you leave P, 0, 1, 2, 3, 4 and E. After an update of the scripts, the setup is written again automatically the first time the wizard opens.
6 AdjustSee below.
7 ChecklistELRS 4 (100Hz Full, Arm using: Switch), Extended limits, failsafe, throttle warning off and switch warning on the motor switch, and alarms for weak signal and low receiver voltage.

Menu 6: Adjust

Thermal / Speed per surfaceThe camber control gives the least throw forward and the most throw back, in both Thermal and Speed. Order: max on both flaps, then each aileron, then min in the same order; Thermal first, then Speed. Min can be 0 %. All wing surfaces stay at their max (or min) while you adjust, so you can compare by eye.
Butterfly (crow)Flaps down and ailerons up per surface at full crow, aileron throw at full crow and differential at full crow.
Elevator with butterflyCurve with 7 points. Move the Throttle stick to the point and adjust. Best done in flight.
Aileron → rudderPer flight mode. Default 0 %. “Copy to all FM” gives the same value in all.
Snap flapFirst max per surface (small, default 20 %), then how much is used in each flight mode (default 0 %). Not in Landing.
Aileron → flapsDown in % of the flap's down throw and up in % of the flap's up throw, the same for both flaps (default 0 %). While you set down or up, both flaps show that throw, so it can be measured. Then how much of it is used in each flight mode: 100 % = exactly the throw you set for down and up (default 100 %, Landing 0 %).
MotorMotor level Low/Medium/Full and motor → elevator.

Hold SH in (the trainer/test switch) in step 4 and menu 6, and all surfaces go to center. This is handy for comparing with neutral. It needs a few free mixes. If the model is nearly full, the hint “Hold SH in” is not shown on the screen.

The values per flight mode apply to the flight mode the radio is in. Change flight mode with the switch while adjusting. The aileron differential is set with trim T3 in flight, with its own value per flight mode.

Flightscreen

Open F3X.no → Flightscreen before launch and leave it open during the flight. The times come from the model's timers (step 5 writes them when the model has a motor), so they keep counting if you close the screen – but the voice and the log only run while it is open.

Flight timeStarts at the first motor on and counts down from 10 min (or 15 min, the «Flight time» button before launch). Voice every minute, with a short jingle before «2 minutes» left, every 10 seconds from 1 minute left and every second from 25. After 0 it keeps counting (shown as +m:ss in red).
MotorMotor time counts down from 30 s while the motor runs (20, 40 or 60 s with the «Motor» button). Voice every 5 seconds and every second for the last 7. Stops at 0. If the motor switch is still on when the time is up, the radio says «motor» every 10 seconds and the screen shows MOTOR OFF! until the motor is switched off.
After motor cutCounts down 10 s from when the motor stops or the motor time runs out (whichever comes first), with voice like the motor time (every second for the last 7) and a beep at 0. Stops at 0.
BatteryTop right: the flight battery if a sensor provides it (VFAS or Bat), otherwise RxBt. Motor battery: the ER8 sends the motor battery as RxBt when its voltage lead (included with the receiver) is connected to the battery – the receiver picks the input itself (4–35 V). Above 6 V «Motor battery» is shown with the cell count (detected while the motor is stopped) and volts per cell: orange below 3.7 V, red below 3.5 V. Adjust offset/ratio on RxBt under MDL → Telemetry so the value matches a voltmeter. Without the lead RxBt is the receiver voltage (red below 4.5 V). The flight log records the battery voltage at motor cut and the lowest voltage per cell.
LinkBelow the battery: RQly in % with a bar (green above 80, orange below, red below 50) and RSSI. «NO LINK» in red when telemetry is lost.
ResetPress twice (only when the motor is stopped) to reset the times before the next flight. «Reset flight» on the radio also works.

Flight log: events are written to LOGS/F3X_<model>_<date>.txt on the SD card: start, motor on/off with motor time, motor time used up, 10 s after cut (with height if the receiver has an altitude sensor), flight mode changes, weak signal, link lost/back and flight time reached. On reset a summary is written with flight time, motor time, lowest RQly and RxBt and max height. The radio also logs all telemetry values and switches to a CSV file in LOGS/ (the special function «Logging to SD»).

The voice uses the radio's numbers. If you set up the model with an older version, the setup is rewritten the first time the wizard or menu 6 is opened, so the timers do not beep as well.

Flight modes

Normal (FM0) when no other is on. Landing (FM1) comes on at 10 % crow and cuts the motor. The motor stays locked until the motor switch is set to off again. Speed (FM3) and Thermal (FM4) on their own switch. With a motor: separate flight modes per motor step with their own elevator trim. English voice callouts when the mode changes.

6. Troubleshooting

ProblemSolution
CH5 is on/off onlyELRS 3, or Arm using is set to CH5. See section 1.
Nothing happens when I turn the potSet S1 and S2 to center (red message on the screen).
A surface follows the stick while adjustingThe model has used all 64 mixes. The screen tells you. Delete mixes on channels the wizard does not use (for example CH10–16 from a default template).
The flap will not go flushAbove approx. 195 % the servo arm must be moved one spline.
A surface is slightly off center after the wizardCheck the channel monitor. If the channel is not at 0 %, a mix is active: flight mode, camber control, crow or trim.
The start page says the channels have changedRun 0–5 again for the model.
“F3X.no needs EdgeTX 2.11 or newer”Update the radio with EdgeTX Buddy (buddy.edgetx.org), 2.12 recommended.
